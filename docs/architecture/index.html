Roundnet app: architecture overview

Roundnet clubs in Karlsruhe and Munich use this app to run their trainings. Members sign up for trainings, see who is coming and pledge what they bring. A drinks list books drinks on a running bill, and a club admin confirms the bill once it is paid. Matches feed an Elo ranking, and push notifications tell members about changes.

Technically it is a React PWA that talks straight to Supabase. Postgres holds the business rules in RLS policies, RPCs and triggers. Edge functions handle push delivery, calendar feeds and the Playerzone scraping.
